# Annotation-and-ChatBot-Training-
It can train, annotate, store entities, and other NLU methods such as Tokenisation too

A complete toolkit for annotating NLU data (intents, entities, tokens) and training chatbot models.
Designed for students, developers, and NLP learners who want a simple, clean workflow to build conversational AI systems.

🌟 Key Features

🎯 Annotation Tool – Mark intents, entities, tokens

🤖 Chatbot Training Pipeline – Train NLU models using your data

📁 Data Storage – Clean JSON/YAML-based annotation storage

🔗 Node.js Backend – For annotation and model operations

🧪 Test Suite Included – Validate your models and preprocessing


🧹 Modular Structure – UI, backend, models, tests separated clearly
